# IT Risk Register  
  
## Project Overview  
This tool maintains a centralized database of identified IT risks. It uses a Likelihood x Impact scoring model (1-5 scale) to calculate total Risk Magnitude.  
  
## Risk Scoring Key  
- **16-25**: Critical Risk (Immediate Action)  
- **10-15**: High Risk (Remediation Required)  
- **Below 10**: Low/Medium Risk
